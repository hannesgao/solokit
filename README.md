# solokit

**solo-agent-coding-kit** — a Claude Code plugin that takes a solo agent-coding project from idea to release: kickoff, PRD, GitHub repo and rules, issue-driven building, mid-project changes, release and retro.

> Status: pre-release. Milestone M0 (spikes) is in progress; nothing is installable yet.

- Product requirements: [docs/PRD.md](docs/PRD.md)
- Conventions the kit implements (and follows itself): [docs/CONVENTIONS.md](docs/CONVENTIONS.md)

Requirements: Claude Code v2.1.287 or later, Node.js 22 or later, `git` and `gh`.
